Ports

Web UI (TCP){{.WebPort}}
Game (UDP){{.AppPort}}

Both ports are managed by this deployment and are read-only here, because Docker fixes its mappings when the container is created. Use the steps below to change them.

How to change the ports

Docker, in server/docker:

sudo ./setup.sh --ports

Or edit .env directly, then restart:

LANPARTY_WEB_PORT={{.WebPort}}
LANPARTY_APP_PORT={{.AppPort}}

sudo docker compose up -d

Native: edit native/web.env and restart run.sh.

Changing the UDP port also means changing the router forward.
