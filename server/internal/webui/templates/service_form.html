Docker firewall reminder

If the game server is on this Docker host, allow the port from Docker's private range. Example for TCP 25565:

sudo ufw allow from 172.16.0.0/12 to any port 25565 proto tcp comment 'LAN Party -> Game'

Remove it later with:

# LAN Party -> Game
sudo ufw delete allow from 172.16.0.0/12 to any port 25565 proto tcp

Use udp for UDP services, and add one rule per port. These rules allow containers on this host only, not your LAN or the internet.
