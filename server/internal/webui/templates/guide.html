Host guide

Host a game night

This page is the short version. Friends use the LAN Party desktop app, not this web UI.

1. Forward UDP

Forward the UDP game port shown in Settings from your router to this host. If the app port is 51820, forward UDP 51820 to this server's LAN address.

Changing the app port in this deployment also means changing the router forward.

2. Set the public address

In Settings, enter the address friends should dial: your public IP or a hostname. It is separate from the address of this web UI.

3. Create a group and a service

Create a group for the game night, then add the game's server port. The target is the game server as this host sees it, for example 127.0.0.1:25565.

4. Invite a friend

Start the session and create an invite. Send the code to your friend. They paste it into the desktop app, and their game connects to 127.0.0.1 with the same port.

An invite works once and expires after an hour.

Keeping it safe

  • Put this web UI behind TLS, usually a reverse proxy such as Caddy or nginx.
  • Do not expose the web UI port unless you need remote administration.
  • Back up the data directory and encrypt the backup: it holds the host keys.
  • The host keys are owner-only files. Do not copy them into chat or tickets.
