# LAN Party 1.0

A LAN cable across the internet. LAN Party gives a friend one local port onto a
game server on your LAN — and nothing else.

## Highlights

- Linux x86-64 AppImage, built on Ubuntu 22.04 against GTK 4.6, GLib 2.72,
  glibc 2.34 and the x86-64 baseline ISA.
- Host and friend groups, saved locally.
- TCP and/or UDP services with an optional friend-side port remap.
- One-time invites, hashed at rest, with a 24-hour expiry.
- Host approval for new devices and changed device keys.
- Live presence, live service updates and immediate revocation.
- Presets for Minecraft Java and Bedrock, Terraria, Valheim, Factorio, Palworld,
  rAthena Ragnarok Online, Stardew Valley, Project Zomboid, 7 Days to Die, Rust,
  Source engine games, ARK, Don't Starve Together, Jellyfin and Plex.
- Fixed 400×640 GTK4 interface, tray, start on login and start minimised.
- No virtual network, no accounts and no telemetry.

## Install

1. Download `lan-party_1.0.0_linux_amd64.AppImage` and `SHA256SUMS` from this
   release.
2. Verify the download:

   ```sh
   sha256sum -c SHA256SUMS
   ```

3. Make it executable and run it:

   ```sh
   chmod +x lan-party_1.0.0_linux_amd64.AppImage
   ./lan-party_1.0.0_linux_amd64.AppImage
   ```

The AppImage uses the system GTK4 runtime and needs FUSE. On Ubuntu 24.04+
install `libfuse2t64`; on Arch install `fuse2`. Without FUSE, run it with:

```sh
./lan-party_1.0.0_linux_amd64.AppImage --appimage-extract-and-run
```

## Requirements

- Linux on x86-64 with X11 or Wayland.
- GTK 4.6, GLib 2.72 and glibc 2.34 or newer.
- One UDP port forwarded on the host's router.
- A public address that reaches the host.

That floor covers Ubuntu 22.04+, Debian 12+, Linux Mint 21+, Pop!_OS 22.04+,
Fedora 36+, and Arch-based systems including SteamOS 3 in Desktop Mode.

## Known limitations

- **Linux x86-64 only.** Windows is planned for 1.1.
- **The host needs a forwarded port and a public address.** A self-hosted relay
  for CGNAT hosts is planned for 1.2.
- **The AppImage uses the system GTK4 runtime.** GTK is not bundled.
- **No auto-update.** Replace the AppImage to update.
- **Friends see the host and themselves, not other friends.** That is
  intentional; the host is the only peer in the tunnel.
- **The old WireGuard-era groups file and keyring keys are not imported.** Move
  the old data folder aside and create those groups again.
